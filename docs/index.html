Run your Mac from your wrist.

WristClaw Bridge is the local Mac companion that lets the WristClaw iPhone and Apple Watch app talk to your own OpenClaw-compatible agent over your private network.

Private by default

Self-repair ready

What It Does

WristClaw Bridge lets the Watch app send short commands to an OpenClaw-compatible agent running on your Mac.

  • Sends typed, dictated, and quick-action prompts from Apple Watch.
  • Returns compact agent replies sized for the Watch.
  • Supports session selection and session creation from the Watch.
  • Can forward screenshots or image attachments back to the Watch.
  • Generates private pairing files for the iPhone app: QR code, deep link, and manual payload.

Quick Start

Use this flow on the Mac that runs your OpenClaw-compatible agent.

Clone and install

Install the bridge dependencies locally.

git clone https://github.com/samboydevelopment/wristclaw-bridge.git
cd wristclaw-bridge
npm install

Run setup

The setup wizard checks Node.js, OpenClaw, Tailscale, local port availability, and your configured agent session.

npm run setup

Start and diagnose

Start the local bridge, then verify health and user-facing diagnostics.

npm start
npm run health
npm run diagnose

Expose privately with Tailscale Serve

Expose only the Watch path through your own Tailscale network.

tailscale serve --bg --set-path /watch http://127.0.0.1:8787

Pair WristClaw

Generate pairing files, open the local pairing page, and scan the QR code from the iPhone app.

npm run pair
open ~/.openclaw/openclaw-watch/pairing.html

Do not publish or share generated pairing files. They include the bearer token used by your iPhone and Watch to reach your bridge.

Requirements

  • macOS with Node.js installed.
  • OpenClaw installed and authenticated on the Mac.
  • Tailscale installed, connected, and signed in.
  • iPhone and Mac connected to the same user-owned Tailscale tailnet.
  • WristClaw installed on iPhone and Apple Watch.

Repair After Updates

OpenClaw or Tailscale updates can occasionally disturb the local bridge path or the Tailscale Serve route. Use the repair command before re-pairing devices.

npm run repair

The repair command verifies local health, checks diagnostics, confirms OpenClaw and Tailscale are available, reapplies the Tailscale Serve route, and regenerates pairing files when needed.

Security Model

  • The bridge binds to 127.0.0.1 by default.
  • Requests require Authorization: Bearer <token> when a token is configured.
  • Generated config is written to ~/.openclaw/openclaw-watch/config.env with private file permissions.
  • Tailscale Serve is the recommended exposure path.
  • Tailscale Funnel or public internet exposure is not part of the default flow.
